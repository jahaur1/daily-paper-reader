## 摘要
准确建模跨变量依赖关系仍然是多变量时间序列预测中的关键挑战，尤其是在存在强周期模式的情况下。许多现有方法依赖于基于注意力的机制，这些机制具有二次复杂度，并且随着变量数量的增加而扩展性较差。最近的无注意力聚合模型通过线性复杂度的核心交互解决了这个问题，但它们没有明确利用数据中存在的全局周期结构。为了克服这一局限性，我们提出了CARNet，一个周期条件核心聚合与再分配框架，通过多头核心聚合将全局循环周期信息整合到高效的核心交互建模中。在多个真实世界多变量预测基准上的大量实验表明，CARNet在多种预测视界上持续优于强Transformer和无注意力基线，同时保持跨变量依赖关系的线性复杂度建模。

## Abstract
Accurately modeling cross-variate dependencies remains a key challenge in multivariate time series forecasting, particularly in the presence of strong periodic patterns. Many existing approaches rely on attention-based mechanisms that incur quadratic complexity and scale poorly with increasing numbers of variates. Recent attention-free aggregation models address this issue through linear-complexity core-based interactions, but they do not explicitly leverage the global periodic structure present in the data. To overcome this limitation, we propose CARNet, a Cycle-Conditioned Core Aggregation and Redistribution framework that integrates global recurrent cycle information into efficient core based interaction modeling via Multihead Core Aggregation. Extensive experiments on multiple real-world multivariate forecasting benchmarks demonstrate that CARNet consistently outperforms strong transformer and non-attention baselines across diverse prediction horizons while preserving linear-complexity modeling of cross-variate dependencies.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究问题**：多变量时间序列预测中，准确建模跨变量依赖关系是核心挑战，尤其当数据存在强周期模式时。现有方法存在两类矛盾：

  - 无注意力聚合模型（如 SOFTS）通过线性复杂度的核心交互解决了扩展性问题，但忽视了数据中蕴含的全局周期结构。
- **动机**：先验工作（CycleNet、TQNet）证明了周期建模的价值，但 CycleNet 未建模跨变量依赖，TQNet 依赖注意力机制，复杂度仍较高。因此，亟需一种既能利用全局周期信息、又保持线性复杂度的跨变量依赖建模方法。
- **整体含义**：本文提出 CARNet，通过**周期条件核心聚合与再分配**框架，将可学习的循环周期作为全局条件信号，集成到高效的核心交互机制中，实现了**周期感知 + 线性复杂度**的跨变量依赖建模，显著提升预测性能。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：在“核聚合-再分配”范式（SOFTS 的星型结构）基础上，引入**周期条件**：利用可学习的循环周期表示作为全局信号，在聚合和再分配阶段都融合周期信息，从而让核心表示同时捕获跨变量依赖和共享的周期模式。
- **关键技术细节**：
  - **可学习循环周期**：借鉴 CycleNet/TQNet，通过自相关分析（ACF）估计数据集的最大稳定周期长度 W，初始化一个可学习的循环矩阵 Q ∈ ℝ^(C×W)，然后根据输入序列的时间索引进行相位对齐，得到周期序列 Z ∈ ℝ^(C×T)。
  - **Cycle-Conditioned Core Aggregation（CCCA）**：将原始输入嵌入 X' 与周期投影 Z' 在特征维度拼接，线性投影 + GELU 得到周期条件变量嵌入 V'。然后通过**多头核心聚合（MHCA）** 提取共享核心：
    - 将 V' 拆分为 h 个头（每头维度 d_head = d/h），每个头用 1D 卷积（kernel=1）提取子核心，再合并、线性变换得到统一的多头核心 θ ∈ ℝ^(C×d')，最后沿变量维度做随机池化得到全局核心 θP ∈ ℝ^(d')。
  - **Cycle-Conditioned Core Redistribution（CCCR）**：将全局核心 θP 广播给所有变量，与 X'、Z' 拼接，经 MLP（两层线性 + GELU）得到细化表示 G，再与 X' 残差连接后通过 FFN，最后线性投影到预测长度 H。
- **算法流程**（文字描述）：
  1. 输入 X ∈ ℝ^(C×T)，通过线性层得到 X'∈ ℝ^(C×d)；
  2. 根据相位对齐得到 Z，线性投影为 Z'∈ ℝ^(C×d)；
  3. 拼接 X' 和 Z'，线性+GELU得 V'∈ ℝ^(C×d)；
  4. 对 V' 执行 MHCA，得到全局核心 θP；
  5. 拼接 X'、Z'、广播后的核心，经 MLP 得到 G；
  6. 残差 X'+G，经 FFN，线性投影得到 Y。
- **时间复杂度**：每层 O(CT d + C d² + C d d' + C (d')² + C d d_ff)，对 C 和 T 均线性。

## 7. 优点

- **创新性**：首次将可学习周期结构直接融合到无注意力核心交互框架中，实现周期感知的线性复杂度跨变量依赖建模。
- **技术亮点**：多头核心聚合（MHCA）打破了单个共享核心的表达瓶颈，通过分区-提取-合并流程增强了表示多样性。
- **实验质量**：在 12 个大规模数据集上全面验证，消融充分，对比公平，鲁棒性分析完备（随机种子、序列长度、周期长度）。
- **效率优越**：避免二次复杂度，实际参数和训练时间在可接受范围内，且性能超过复杂注意力模型（如 TQNet）。
- **实用性**：方法设计简洁，模块化清晰，易于实现和部署（提供官方代码）。

## 8. 不足与局限

- **周期长度固定**：周期长度 W 在数据集级别通过 ACF 估计并固定，而不是自适应每个样本，对于周期弱、不规则或非平稳的数据可能效果下降（作者在原文 Limitations 中明确提到）。
- **依赖变量相关性**：作为通道依赖模型，在变量间相关性弱的数据集上优势会减小。
- **架构敏感性**：性能仍依赖于隐藏层维度、层数等超参数的选择，虽实验覆盖常见范围，但未提供自适应的调参策略。

- **应用边界**：主要适用于具有明确周期性且变量间存在强相关性的场景（如电力、交通），不适用于随机/无周期序列。
